AutoPoster_TMS_bot

Automated Portfolio & Art Publishing Tool

🎨 About the Application

AutoPoster_TMS_bot is a private content-management tool designed to streamline the workflow of digital artists. It allows automated cross-publishing of original artwork, illustrations, and process sketches from a local studio environment directly to connected social media accounts, including Pinterest, Telegram, and Tumblr.

⚡ Key Features

  • Automated high-resolution image posting
  • Custom board selection and tag formatting
  • Direct linking back to original art portfolios
