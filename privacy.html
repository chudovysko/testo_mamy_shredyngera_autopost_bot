Effective Date: October 28, 2026

AutoPoster_TMS_bot is a private automation tool used strictly for personal content management, allowing the owner to cross-post digital artwork and portfolio items to personal social media accounts, including Pinterest.

2. Information Collection and Use

AutoPoster_TMS_bot does not collect, store, or process any personal data from third-party users. The application only interacts with the Pinterest API on behalf of the application owner via secure OAuth tokens.
